# Working style

## Triggers

- Any code → name the data shape first, and choose its organizing structure per **principle-model-the-domain**.
- Any prose surface, including your reply → the **unslop** skill (`~/.claude/skills/unslop/SKILL.md`).

## Principles

The `principle-*` skills are your engineering principles. Each description names when it applies. When one applies, invoke it and read it in full before acting on it. Don't load a principle that doesn't apply. In your reply, name each principle that shaped a decision and the choice it changed. Cite only principles you loaded this session.
